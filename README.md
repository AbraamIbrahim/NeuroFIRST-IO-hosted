# NeuroFIRST Triage Tool

A triage assessment tool built for the NeuroFIRST clinic at UVA Health.

## How to run the frontend locally:
    'cd' into the /front directory
    make sure you have npm and npx installed
    install serve through npx
    serve -l [PORT] or npx serve -l [PORT]

### Overview
A specialized clinical decision support interface built for the NeuroFIRST clinic at UVA Health. This tool allows clinicians to rapidly input patient demographics and neurological symptoms to assist in triage evaluation and priority leveling.

### Prerequisites (for local hosting)
- Node.js
- npm or npx
